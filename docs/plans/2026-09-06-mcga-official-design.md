# MCGA Official Website Design

## Goal

Create a concise, single-page company website for MCGA TECHNOLOGIES LLC. It should communicate the company behind StayLink and establish trust through clarity, reliability, security, and cross-platform reach.

## Chosen Direction

**Dark network console.** The site uses a near-black, blue-green palette, precise technical typography, a live-looking grid, and animated connection paths. It should feel like a calm, dependable control surface rather than a generic SaaS landing page.

## Structure

1. **Navigation** — MCGA wordmark, anchored section links, and a compact StayLink product link.
2. **Hero** — Strong statement: reliable connection as foundational infrastructure; a primary product CTA; a network-orbit visual and short status indicators.
3. **About / mission** — Explain MCGA and its focus on thoughtfully designed connectivity software.
4. **Capabilities** — Four feature cards: secure connections, cross-platform experience, streamlined management, and continuous improvement.
5. **Commitment** — A trust-focused panel covering privacy, service reliability, and responsive support.
6. **Footer** — Company name, country, support email, and StayLink link.

## Interaction and Responsive Behavior

- Anchor links scroll smoothly to sections.
- A mobile menu opens and closes from the navigation control.
- Subtle load, hover, and network-line animations add atmosphere without blocking reading.
- The layout collapses cleanly to one column below tablet width and supports reduced-motion preferences.

## Implementation

Use a lightweight static HTML, CSS, and JavaScript site so it can run without a build dependency. Keep all visual styling in CSS, use semantic HTML, and ensure adequate text contrast and keyboard-accessible controls.

## Validation

- Confirm navigation and mobile menu behavior in a browser-capable local preview.
- Check that content, links, and responsive layout render without errors.
- Run available static checks when the project structure provides them.
