# MCGA Typography Refresh

Replace the dense technical type pairing with a restrained corporate pairing: Lora for headings and Source Sans 3 for body, navigation, and product details. Chinese text continues to prefer appropriate system sans-serif fallbacks.

The refresh reduces all-caps use and excessive tracking outside micro-labels, and adjusts heading/body line-height for a calmer, more readable company-site rhythm. The dark network-console visual identity remains unchanged.
